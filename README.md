# Ama — Personal Portfolio

A single-page personal portfolio built solo with HTML, CSS, and JavaScript — designed mobile-first from the ground up.

🔗 **Live site:** [https://ama-dev-portfolio.netlify.app/]

## About

This portfolio showcases my frontend development work as a 300-level Computer Science student at the University of Nigeria, Nsukka. It's built entirely with vanilla HTML, CSS, and JavaScript — no frameworks — as a deliberate way to strengthen my core fundamentals before moving into React.

## Features

- Fully responsive, mobile-first layout using CSS Grid and Flexbox
- Custom typewriter-style animated tagline (vanilla JavaScript)
- Smooth scroll navigation between sections
- Reusable design system built with CSS custom properties (variables)
- Sticky, blurred navigation bar
- Project showcase section linking to live deployments and source code

## Built With

- **HTML5** — semantic, accessible markup
- **CSS3** — Flexbox, Grid, custom properties, `clamp()` for fluid typography, mobile-first media queries
- **JavaScript (Vanilla)** — DOM manipulation, event handling, no external libraries or frameworks
- **Fonts:** Fraunces (display), Sora (body), IBM Plex Mono (labels/utility)

## Sections

1. **Hero** — introduction and primary calls to action
2. **About** — background, current focus, and goals
3. **Work** — featured projects with live links and source code
4. **Skills** — technical skills, organized by category
5. **Contact** — ways to reach me

## Running Locally

This is a static site with no build step or dependencies required.

1. Clone the repository:
   ```
   git clone https://github.com/grace406/my-portfolio-website.git
   ```
2. Open `index.html` directly in your browser, or use a local development server (e.g., VS Code's Live Server extension) for the best experience.

## Deployment

Deployed via [Netlify](https://netlify.com), connected directly to this GitHub repository — pushes to the `main` branch deploy automatically.
